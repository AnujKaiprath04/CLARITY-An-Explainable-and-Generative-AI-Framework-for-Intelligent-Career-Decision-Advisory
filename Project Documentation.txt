CLARITY: An Explainable and Generative AI Framework for Intelligent Career Decision Advisory

📖 Project Overview

This project is an advanced, domain-specific AI chatbot tailored to assist students in making crucial career decisions (Job vs. Higher Studies vs. Startup). It leverages Machine Learning for predictive analysis, Explainable AI (SHAP) for transparent reasoning, and Generative AI (OpenAI LLM) for human-like strategic advisory.

Module Explanation

Frontend (Streamlit): Manages state, handles routing securely, and provides a reactive user experience.

Predictive Model (Scikit-Learn): A Random Forest model trained on synthetic historical student data to predict the highest-probability path.

XAI Module (SHAP): Calculates Shapley values to explicitly state why the ML model made its prediction, mitigating the "black box" problem.

GenAI Module (OpenAI): Acts as the reasoning layer. It translates mathematical probabilities and SHAP scores into actionable, empathetic human language.

🎓 Viva Questions and Answers

Q1: Why did you choose Random Forest over Deep Learning for this project?
Answer: Deep Learning requires massive datasets and is inherently a "black box". Random Forest is highly compatible with TreeSHAP, allowing for precise, fast calculation of feature importance, which aligns with the primary goal of this project: Explainable AI. It also handles tabular data exceptionally well.

Q2: What is SHAP, and how does it work in your system?
Answer: SHAP (SHapley Additive exPlanations) is a game-theoretic approach to explain the output of ML models. In our system, it calculates the marginal contribution of each user trait (e.g., Risk Tolerance) to the final prediction (e.g., Startup). This allows the system to tell the user why a specific career was recommended.

Q3: How is the Generative AI (LLM) utilizing the ML outputs?
Answer: We use advanced Prompt Engineering. The LLM is injected with a system prompt defining its persona. We then pass the user's raw data, the ML model's prediction, and the top 3 SHAP values into the user prompt. The LLM synthesizes this quantitative data into a qualitative, step-by-step action plan.

Q4: What are the ethical considerations of your project?
Answer: The primary ethical consideration is "Algorithmic Bias"—if the training data is biased, the advice will be biased. Also, AI should act as an advisor, not a definitive decision-maker (human-in-the-loop). We enforce this by outputting a "Confidence Score" and "Alternative Options".

🚀 Deployment Guide

Local Deployment

Open Terminal/Command Prompt.

Run pip install -r requirements.txt.

Run python generate_data.py (Creates the dataset).

Run python train_model.py (Creates the ML models).

Run streamlit run app.py (Starts the UI).

Streamlit Cloud Deployment

Push all files (app.py, requirements.txt, models/ folder) to a GitHub repository. (Note: Do not push API keys).

Go to share.streamlit.io and link your GitHub account.

Select your repository and set the main file path to app.py.

Click "Deploy".

🔮 Future Enhancements & Limitations

Enhancements: Integration with real-time job market APIs (LinkedIn/Glassdoor) to adjust predictions based on current economic trends. Integrating an external Database (PostgreSQL/Firebase) to save user historical progress.

Limitations: The current model relies on self-reported psychometric data, which can be prone to self-reporting bias. The system relies on external LLM APIs which require internet connectivity and incur latency/costs.
